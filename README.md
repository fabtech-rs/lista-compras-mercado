# Minha Compra — Lista de Supermercado

Projeto em HTML, CSS e JavaScript puro.

## Funcionalidades

- Criação da lista antes da compra
- Nome da lista e do mercado
- Lista original bloqueada após iniciar a compra
- Marcação dos produtos pegos
- Quantidade realmente comprada e valor unitário
- Itens comprados fora da lista
- Total do carrinho em tempo real
- Comparação com preços de compras anteriores
- Resumo de itens faltantes, extras e quantidades diferentes
- Conferência com o total do documento fiscal
- Histórico de compras
- Persistência com localStorage

## Estrutura

```text
lista-supermercado-v2/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
```
